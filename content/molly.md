Molly is my first venture into hardware accelerated computer graphics. It is a real-time OpenGL renderer, that I built to
explore the space of real-time grahics with the help of 
<a href="https://learnopengl.com/" target="_blank">LearnOpenGL.com</a> as learning material. This was my final project before taking a 
hiatus from graphics in order to learn more maths.
The project can be found on my
<a href="https://github.com/Veil43/molly">GitHub</a>.
